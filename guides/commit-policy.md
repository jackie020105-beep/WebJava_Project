# 커밋 메시지 정책

```text
type: 변경 요약 (#이슈번호)
```

| 타입 (Type) | 설명 |
| :--- | :--- |
| **feat** | 새로운 기능 추가 |
| **fix** | 버그 수정 |
| **docs** | 문서 수정 (README, 주석 등) |
| **style** | 코드 포맷팅, 세미콜론 누락 등 기능에 영향이 없는 스타일 수정 |
| **refactor** | 코드 리팩토링 (기능 변화 없음) |
| **test** | 테스트 코드 추가 또는 기존 테스트 수정 |
| **chore** | 빌드 업무 수정, 패키지 매니저 설정 등 기타 작업 (프로덕션 코드 무관) |
| **perf** | 성능 개선 |
| **ci** | CI/CD 관련 설정 수정 |
